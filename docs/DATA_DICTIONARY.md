# Data Dictionary

The public sample data is generated by `src/generate_sample_data.py`.

| Column | Type | Description |
|---|---|---|
| `transaction_id` | string | Unique transaction identifier |
| `transaction_date` | date | Date of transaction |
| `drug_category` | string | Drug category or commercial category |
| `product_id` | string | Product/SKU identifier |
| `region` | string | Commercial geography |
| `channel` | string | Sales channel |
| `customer_segment` | string | Customer group |
| `units_sold` | integer | Number of units sold |
| `unit_price` | float | Listed unit price |
| `gross_sales` | float | Sales before discount |
| `discount_rate` | float | Discount rate between 0 and 1 |
| `discount_amount` | float | Gross sales multiplied by discount rate |
| `net_sales` | float | Sales after discount |
| `campaign_flag` | integer | 1 if transaction belongs to a campaign-like group, otherwise 0 |
| `month` | string | Month bucket derived during cleaning |
| `quarter` | string | Quarter bucket derived during cleaning |
| `average_selling_price` | float | Net sales divided by units sold |

## Grain

The base table is transaction-level. Forecasting uses month-category aggregation. Segmentation uses category/product/customer-level feature aggregation depending on the analysis.

## Important Note

The sample file is synthetic. It is useful for demonstrating analytics logic, but not for claiming real pharma business results.

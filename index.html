Tools

I used simple tools because this is a business analytics project.

The point is not to show a complex model. The point is to show a clean path from rows to numbers to a readable dashboard.

SQL I use it because sales data usually sits in tables.
pandas I use it to clean rows, group data, make new fields, and export tables.
Ridge regression I use it as a simple forecast model that handles related features better than plain linear regression.
LightGBM I added it as the stronger tree-based baseline, then kept the final claim honest because it did not beat the simpler models on this test block.
K-means I use it to group categories into high-value growing, stable core, campaign-responsive, and low-volume niche segments.
Bootstrap CI I use it to compare campaign rows without pretending it proves cause and effect.

Limits

I say what this is and what it is not.

This is commercial analytics with generated public data. I make no clinical claims, no production claims, and no fake causal claim.

Data I use generated public data so the repo can be run and checked safely.
Campaign comparison I treat campaign analysis as comparison-only unless randomization is documented.
Domain I make no patient, drug efficacy, safety, or clinical recommendation claims.

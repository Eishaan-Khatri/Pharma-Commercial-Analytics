# Publishing Notes

This folder is meant to live here:

```text
https://github.com/Eishaan-Khatri/Pharma-Commercial-Analytics
```

The project page lives in:

```text
index.html
assets/site.css
assets/site.js
```

After pushing, GitHub Pages should serve the site at:

```text
https://eishaan-khatri.github.io/Pharma-Commercial-Analytics/
```

If the page does not open right away, wait a few minutes and check:

```text
Settings -> Pages -> Deploy from a branch -> main -> /root
```

GitHub Pages sometimes needs one clean publish cycle before the public URL works.

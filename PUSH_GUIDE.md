# Publishing Notes

This folder is meant to be published as its own GitHub repository:

```text
https://github.com/Eishaan-Khatri/Pharma-Commercial-Analytics
```

The project includes a GitHub Pages-ready static case-study site at:

```text
index.html
assets/site.css
assets/site.js
```

After the repository is pushed, enable GitHub Pages from:

```text
Settings -> Pages -> Deploy from a branch -> main -> /root
```

The public project website should then become available at:

```text
https://eishaan-khatri.github.io/Pharma-Commercial-Analytics/
```

If the public URL does not open immediately, wait a few minutes and check the
repository's Pages settings. GitHub Pages usually needs one successful publish
cycle before the URL becomes live.
